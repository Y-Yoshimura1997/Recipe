# チーズケーキ(バスク風)

チーズケーキ部
| 材料 | 分量 |
| :----------- | :----------- |
|  砂糖         |  60g        |
|  全卵         |  2個         |
|  レモン汁      |   半分        |
|  小麦粉        |  大2         |
|  生クリーム     |   200cc     |
|   クリームチーズ  |   200g    |


タルト生地
| 材料 | 分量 |
| :----------- | :----------- |
|  バター       |  50g   |
|  砂糖      |  30g   |
|  卵黄     |  1個   |
|  小麦粉       |  120g   |


1. 型でタルト生地をこねて，貼り付ける．
2. ミキサーでチーズケーキ部を混ぜる．ハンドミキサーを使用する際は，クリームチーズだけを生クリームで伸ばしながら混ぜていく．
3. 型に2.を流し込む
4. オーブンで180℃，45分焼く．


# シフォンケーキ(18cm)

| 材料 | 分量 |
| :----------- | :----------- |
|薄力粉       |85g  |
|ベーキングパウダー |3g  |
|グラニュー糖    |50g |
|卵黄        |2   |
|サラダ油      |35g  |
|牛乳        |100g | 



| 材料 | 分量 |
| :----------- | :----------- |
|卵白 |100g(約卵3個)  |
|グラニュー糖    |75g |


1. 卵とグラニュー糖を混ぜる
2. そこへ，牛乳を入れたのち，サラダ油を少しずつ加える
3. 別のボールで，卵白でメレンゲをグラニュー糖を少しずつ加えながら作る
4. 2.にメレンゲを２，３回に分けて加える
5. 型に入れて170℃，40分焼く．




# ジェノワーズ(21cm, 15cm*2)


| 材料 | 分量 |
| :----------- | :----------- |
| 卵           | 4個    |
| 砂糖          | 120g   | 
| 薄力粉         | 100g     |        
| コンスターチ      | 20g    |
| バター         | 40g    |
| バニラエッセンス    | 少々   |

1. 卵と砂糖を45度ぐらいで湯煎しながら，パール状の光沢が出るまで泡立てる
2. 薄力粉コンスターチを加えて，全体が繋がるように混ぜる
3. バターとバニラエッセンスを加えて全体がなじむように混ぜる 
4. 160-170℃で，21cm(35分)・15cm(27分)焼く


# パウンドケーキ
| 材料          | 分量   |
| :----------- | :----------- |
| 卵            | 2個   | 
| 砂糖          | 110g   | 
| 薄力粉         | 110g   | 
| 無塩バター      | 110g |
| ベーキングパウダー  | 5g |  
| アーモンドパウダー  | 15g あれば |

1. 砂糖と無塩バターを常温に戻し，ミキサーで白くなるまで混ぜる
2. 常温に戻した卵を少しずつ加えて，ミキサーで混ぜる
3. ベーキングパウダーを加えて，ミキサーで混ぜる 
4. 薄力粉とベーキングパウダーを加えて，ゴムベラで混ぜる
5. 型に入れて，170℃で40分焼く


# ティラミス
| 材料 (フィンガービスケット)         | 分量   |
| :----------- | :----------- |
| 卵            | 2個   | 
| 砂糖          | 60g   | 
| 薄力粉         | 60g   | 

1. 卵を黄身と白身に分ける
2. 砂糖の1/3を黄身に，2/3を白身に入れる
3. 黄身は白っぽくなるまで，白身は角が立つまでミキサーで混ぜる
4. 白身の1/4を黄身に移して混ぜ合わせ，再び白身と混ぜ合わせる
5. 薄力粉を振るって，ゴムベラで混ぜ合わせる
6. キッチンペーパーの上に広げ，170℃のオーブンで15分焼く

| 材料 (マスカルポーネクリーム)         | 分量   |
| :----------- | :----------- |
| 卵            | 1個   | 
| マスカルポーネ   | 125g   | 
| 砂糖　         | 16g   | 

1. 卵を黄身と白身に分ける
2. 砂糖の1/3を黄身に，2/3を白身に入れる
3. 黄身にマスカルポーネを加える
4. 黄身は白っぽくなるまで，白身は角が立つまでミキサーで混ぜる
5. すべてを混ぜ合わせる

| 材料 (コーヒーソース・トッピング)      | 分量   |
| :----------- | :----------- |
| エスプレッソ    | 60ml   | 
| 砂糖          | 10g   | 
| リキュール(グランマニエ・ラム酒など)      | 10ml   |
| ココアパウダー   | 適量   |

1. エスプレッソ・砂糖・リキュールを混ぜて，コーヒーソース作る
2. コーヒーソースにフィンガービスケットを浸し，型に並べる
3. 型にマスカルポーネクリームを乗せて，食べる直前にココアパウダーをトッピングする
